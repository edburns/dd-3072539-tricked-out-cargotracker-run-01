The resolved facade contract is `void changeDeadline(String trackingId, Date arrivalDeadline)`. Convert only the identifier with `new TrackingId(trackingId)` and pass the same `Date` to the application service. Research established that `java.util.Date` is already the historical facade convention; a command DTO or formatted-string parameter would add needless conversion and is rejected. The facade shields the web layer from domain types and must not duplicate aggregate or repository work.
