## Implement

Create:

Update after validation:

- `1-trick-out-01-remove-before-merge/evidence-matrix.md`

Required shape:

```java
@Named
@ViewScoped
public class ChangeArrivalDeadlineDate implements Serializable {
    private static final long serialVersionUID = 1L;

    private String trackingId;
    private CargoRoute cargo;
    private Date arrivalDeadlineDate;

    @Inject
    private BookingServiceFacade bookingServiceFacade;
}
```

Provide `getTrackingId()` / `setTrackingId(String)`, `getCargo()`, `getArrivalDeadlineDate()` / `setArrivalDeadlineDate(Date)`, `load()`, and `changeArrivalDeadline()`.

`load()` must request `bookingServiceFacade.loadCargoForRouting(trackingId)`, retain the DTO, parse `cargo.getArrivalDeadlineDate()` with a new `SimpleDateFormat("MM/dd/yyyy")`, and retain the resulting editable `Date`. Surface malformed data as a clear application/view error consistent with existing JSF behavior; never swallow it, print-only, or turn it into null.

`changeArrivalDeadline()` must reject null, call `bookingServiceFacade.changeDeadline(trackingId, arrivalDeadlineDate)`, and only after success call `PrimeFaces.current().dialog().closeDynamic("DONE")`. A facade failure must remain visible and leave the dialog open.

Add a container-free JUnit test where practical, using a hand-written fake facade. Cover correct tracking-ID load, parsing of the DTO date, submission of the chosen ID/date, malformed DTO input, and null selection.

Update the evidence matrix after implementation and validation with exact commands and results.

- `cd demo && ./mvnw clean package -Popenliberty` succeeds under Java 17.

## Out of scope

Do not add a domain lookup, repository injection, shared mutable `SimpleDateFormat`, new DTO field, formatted-string facade API, chronological rule, mocking framework, dialog launcher, XHTML page, dashboard command link, runtime migration, or unrelated UI redesign.
